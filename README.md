# emthree Minecraft Bedrock Wiki

Documentation for addons running on the emthree Bedrock server. Built with [mdBook](https://rust-lang.github.io/mdBook/) and deployed to GitHub Pages.

## Reading the wiki

Published at: https://morrissimo.github.io/emthree-mc-bedrock/

## Source of truth

Recipe details are verified directly from addon source files. The official Dorios Studios wiki is often outdated or incorrect — cross-check here first.

## Building locally

```
cargo install mdbook
mdbook serve
```
