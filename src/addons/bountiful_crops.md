# Bountiful Crops

Resource crops — plant a seed, harvest a renewable supply of materials that would otherwise require mining, mob grinding, or trading. Part of the UtilityCraft addon family; everything crafts at a vanilla crafting table.

All crops are also compatible with the [Bonsai](bountiful_bonsais.md) for fully automated hands-off production.

## Harvesting

Plant seeds on farmland and harvest when fully grown. Each harvest yields:

- **Primary drop** — the resource (amounts vary by crop, see table below)
- **5% seed drop** — small chance to yield an extra seed (self-sustaining once established)
- **Fortune bonus** — Fortune-enchanted tools add a second chance roll on the primary drop
