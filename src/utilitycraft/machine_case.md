# Machine Case

The machine case is a required component for most UC machines. Crafted at the [UC Workbench](workbench.md).

## Recipe (UC Workbench, shaped)

```
S I S
G R G
S I S
```

| Symbol | Item |
|--------|------|
| `S` | steel_ingot |
| `I` | iron_ingot |
| `G` | gold_ingot |
| `R` | redstone_block |

## Uses

Machine cases appear as ingredients in:

- [Crusher](crusher.md)
- [Infuser](infuser.md)
- All generator tiers
- Wind turbine
- Tiered machine upgrades (UC Tiered Machinery)
