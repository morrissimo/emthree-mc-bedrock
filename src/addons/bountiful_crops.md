# Bountiful Crops

Resource crops — plant a seed, harvest a renewable supply of materials that would otherwise require mining, mob grinding, or trading. Part of the UtilityCraft addon family; seeds are crafted and grown at vanilla crafting tables and farmland.

All crops are also compatible with the [Bonsai](bountiful_bonsais.md) for fully automated hands-off production.

---

## Getting Started

### Step 1 — Craft Base Seeds

All resource seeds start from **base seeds**, crafted at a vanilla crafting table.

Pattern: `B O B / O S O / B O B` (Glass=B, Bone Meal=O, Wheat Seeds=S)

### Step 2 — Craft Type-Specific Seeds

Wrap 8× of the target material around a base seed:

Pattern: `M M M / M S M / M M M` — 8× material (M), 1× base seeds (S) → resource seeds

This works the same for every crop type. The material you use determines which seed you get.

---

## Harvesting

Plant seeds on farmland and harvest when fully grown. Each harvest yields:

- **Primary drop** — the resource (amounts vary by crop, see table below)
- **5% seed drop** — small chance to yield an extra seed of the same type (self-sustaining once established)
- **Fortune bonus** — using a Fortune-enchanted tool adds a second chance roll on the primary drop

| Nether Star Fragment | Nether Star |
